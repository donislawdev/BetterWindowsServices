Ce conține versiunea

FișierCe este
{{archive_window}}Fereastra: BetterWindowsServices.exe, un singur executabil independent cu propriul runtime .NET în interior
{{archive_cli}}Linia de comandă: bws.exe, un singur executabil independent, pentru scripturi, sarcini programate și CI
{{archive_installer}}Programul de instalare: ambele programe în Program Files pentru fiecare cont de pe mașină, fereastra în meniul Start și bws în PATH-ul mașinii

Luați unul sau pe amândouă - sunt doi clienți ai aceluiași motor și niciunul nu îl cere pe celălalt. Pe un server, linia de comandă este cea mai mică dintre ele și face tot ce face fereastra.

Programul de instalare conține exact ce conțin cele două arhive. Se instalează silențios cu msiexec /i {{archive_installer}} /qn, o versiune mai nouă se instalează peste una mai veche și nu închide nimic din ce rulează - așa că închideți fereastra și orice bws care rulează înainte de actualizare, pentru că o copie lăsată să ruleze se poate opri cu o eroare. Dezinstalarea din Setări, Aplicații elimină programele, intrarea din meniul Start și intrarea din PATH și lasă fișierele dumneavoastră în pace.

Executabilele poartă o semnătură Authenticode, așa că Windows numește editorul în loc să avertizeze despre unul necunoscut.

Cerințe

  • Windows 10 versiunea 1809 sau mai nou, ori Windows Server 2019 sau mai nou. Doar pe 64 de biți - un proces pe 32 de biți citește căi și chei de registru redirecționate, ceea ce ar produce în tăcere răspunsuri greșite.
  • Fără .NET de instalat. Ambele executabile poartă propriul runtime .NET.
  • Drepturi de administrator pentru a schimba orice. Citirea, căutarea, instantaneele și comparațiile funcționează și fără, cu mai puține intrări vizibile, iar instrumentul spune asta sus, în loc să se prefacă că lista este toată mașina.

Fereastra păstrează un singur fișier al ei - aranjamentul în care ați lăsat lista - sub %APPDATA%\BetterWindowsServices. Un instantaneu merge acolo unde îi spuneți lui bws snapshot create să-l pună, iar în directorul curent când nu spuneți.

Programul vorbește engleza. Fereastra citește un fișier de limbă, languages\gui.<cod>.json, așezat lângă ea și ales după limba Windows, fără comutator. O traducere este deci o contribuție care se poate adăuga fără recompilare - CONTRIBUTING.md spune cum.

Antivirus și EDR

Acest instrument face ceea ce face un administrator cu serviciile, iar o parte din asta este exact ceea ce urmărește software-ul de securitate.

Oprește și pornește servicii, poate încheia procesul din spatele unuia și citește descriptorul de securitate și privilegiile necesare ale fiecărui serviciu. Un EDR care semnalează un proces ce încheie svchost.exe își face treaba, iar o oprire forțată de aici poate arăta exact așa.

Ce nu face, ca să puteți verifica afirmația: nu injectează nimic în niciun proces, nu împachetează și nu ofuscă nimic, nu instalează niciun serviciu și niciun driver și nu lasă nimic să ruleze, și nu deschide nicio conexiune de rețea. Este open source sub GPL-3.0 și puteți compila singur ambele executabile.

Dacă politica dumneavoastră cere o excepție, excludeți cele două executabile după fișier, nu după folder. Singurul lucru care merită tratat cu aceeași grijă ca instrumentul însuși este un fișier de instantaneu: descrie întreaga mașină.

Compilarea din sursă

.NET 10 SDK, pe Windows.

git clone {{repo}}
cd BetterWindowsServices
dotnet build BetterWindowsServices.slnx -c Release
dotnet test BetterWindowsServices.slnx -c Release

Unele teste citesc managerul real de servicii al mașinii pe care rulează și compară ce spune acest instrument cu ce spune sc.exe. Sunt doar pentru citire. Executabilele dintr-un singur fișier pe care le poartă versiunile sunt aceste două publicări, fiecare un singur fișier cu runtime-ul în interior:

dotnet publish src/Bws.Cli/Bws.Cli.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
dotnet publish src/Bws.Gui/Bws.Gui.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true

Ajung ca bws.exe și BetterWindowsServices.exe sub bin/Release/.../win-x64/publish/ al fiecărui proiect. Fișierele .pdb de lângă ele sunt simboluri de depanare, iar nimic nu are nevoie de ele pentru a rula.

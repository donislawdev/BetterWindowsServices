{{archive_cli}}Příkazový řádek: bws.exe, jeden samostatný spustitelný soubor, pro skripty, naplánované úlohy a CI

Vezměte si jeden nebo oba - jsou to dva klienti téhož jádra a žádný nepotřebuje druhého. Na serveru je příkazový řádek menší z nich a dělá všechno, co okno.

Instalační program nese přesně to, co oba archivy. Instaluje se tiše příkazem msiexec /i {{archive_installer}} /qn, novější verze se nainstaluje přes starší a nic, co běží, nezavírá - zavřete tedy před aktualizací okno i každý běžící bws, protože ponechaná běžící kopie se může zastavit s chybou. Odinstalování v Nastavení, Aplikace odstraní programy, položku v nabídce Start i položku v PATH a vaše vlastní soubory nechá být.

Spustitelné soubory nesou podpis Authenticode, takže Windows uvádí vydavatele místo varování před neznámým.

Požadavky

  • Windows 10 verze 1809 nebo novější, nebo Windows Server 2019 nebo novější. Pouze 64bitové - 32bitový proces čte přesměrované cesty a klíče registru, což by tiše vedlo ke špatným odpovědím.
  • Žádné .NET k instalaci. Oba spustitelné soubory nesou vlastní runtime .NET.
  • Práva správce k jakékoli změně. Čtení, hledání, snímky a porovnání fungují i bez nich, s menším počtem viditelných položek, a nástroj to říká nahoře místo předstírání, že seznam je celý stroj.

Okno uchovává jeden vlastní soubor - rozvržení, v jakém jste nechali seznam - v %APPDATA%\BetterWindowsServices. Snímek jde tam, kam bws snapshot create řeknete, a když neřeknete, do aktuálního adresáře.

Program mluví anglicky. Okno čte jazykový soubor languages\gui.<kód>.json, uložený vedle něj a vybraný podle jazyka Windows, bez přepínače. Překlad je tedy příspěvek, který lze přidat bez nového sestavení - CONTRIBUTING.md říká jak.

Antivirus a EDR

Tento nástroj dělá to, co správce se službami, a část toho je přesně to, co bezpečnostní software sleduje.

Zastavuje a spouští služby, může ukončit proces za nimi a čte u každé služby popisovač zabezpečení a požadovaná privilegia. EDR, který označí proces ukončující svchost.exe, dělá svou práci, a vynucené zastavení zde může vypadat přesně takto.

Co nedělá, abyste to mohli ověřit: nic nevkládá do žádného procesu, nic nebalí ani neobfuskuje, neinstaluje žádnou službu ani ovladač, nenechává nic běžet a neotevírá žádné síťové spojení. Je open source pod GPL-3.0 a oba spustitelné soubory si můžete sestavit sami.

Pokud vaše politika vyžaduje výjimku, vyjměte ty dva spustitelné soubory podle souboru, ne podle složky. Jediná věc, se kterou stojí za to zacházet stejně pečlivě jako s nástrojem samotným, je soubor snímku: popisuje celý stroj.

Sestavení ze zdrojového kódu

.NET 10 SDK, na Windows.

git clone {{repo}}
cd BetterWindowsServices
dotnet build BetterWindowsServices.slnx -c Release
dotnet test BetterWindowsServices.slnx -c Release

Některé testy čtou skutečného správce služeb stroje, na kterém běží, a porovnávají, co říká tento nástroj, s tím, co říká sc.exe. Jsou jen pro čtení. Jednosouborové spustitelné soubory, které vydání nesou, jsou tyto dvě publikace, každá jeden soubor s runtime uvnitř:

dotnet publish src/Bws.Cli/Bws.Cli.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
dotnet publish src/Bws.Gui/Bws.Gui.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true

Skončí jako bws.exe a BetterWindowsServices.exe pod bin/Release/.../win-x64/publish/ každého projektu. Soubory .pdb vedle nich jsou ladicí symboly a ke spuštění je nic nepotřebuje.

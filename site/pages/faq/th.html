คำถาม

คำถามและข้อจำกัด

เครื่องมือที่ปล่อยให้บางอย่างหลุดไปเงียบๆ แย่กว่าเครื่องมือที่บอกว่าทำอะไรไม่ได้ ข้อจำกัดอยู่ในหน้านี้ด้วย แบ่งเป็นสองกลุ่ม: สิ่งที่มันปฏิเสธโดยการออกแบบ และสิ่งที่ Windows ทำซึ่งเครื่องมือนี้รายงานตามที่เป็น

ต่างจาก sc.exe, Get-Service หรือ services.msc อย่างไร

sc query และ Get-Service บอกว่าอะไรกำลังทำงาน services.msc ให้คุณเปลี่ยนมันได้ทีละแถว โดยถามคำถามไม่ได้และไม่มีบันทึกหลังจากนั้น เครื่องมือนี้ถามคำถามได้ (start:auto !status:running) แสดงแผนให้คุณดูก่อนลงมือ และเก็บสแนปช็อตที่คุณ diff ได้อีกสัปดาห์ต่อมา เมื่อมันไม่ตรงกับ sc.exe เรื่องบริการใดบริการหนึ่ง นั่นคือบั๊ก ส่วนหนึ่งของชุดทดสอบรันทั้งสองแล้วเปรียบเทียบทีละรายการ เปรียบเทียบฉบับยาวอยู่ที่นี่

ต้องใช้อินเทอร์เน็ตไหม

ไม่เลย ไม่มีเทเลเมทรี ไม่มีการตรวจหาอัปเดต ไม่มีการรายงานการแครช ไม่มีบัญชี ไม่เป็นไคลเอนต์ของอะไรทั้งสิ้น ครั้งเดียวที่มันอาจแตะเครือข่ายคือเมื่อคุณส่ง --follow-network: เมื่อนั้นมันอาจดูพาธการเปิดใช้งานบนโฟลเดอร์แชร์ของเครื่องอื่น และให้ Windows ดึงใบรับรองที่เครื่องนี้ยังไม่มี ปิดไว้เป็นค่าเริ่มต้น และวิธีใช้บอกเหตุผล ปุ่ม GitHub และ Donate ในหน้าต่างและหน้าในเมนู Help แต่ละอันส่งที่อยู่คงที่หนึ่งแห่งให้เบราว์เซอร์ของคุณเมื่อคุณกด และเบราว์เซอร์ของคุณคือสิ่งที่เชื่อมต่อ

ต้องใช้สิทธิ์ผู้ดูแลระบบไหม

ถ้าแค่ดู ไม่ต้อง ถ้าจะเปลี่ยน ต้อง ถ้าไม่มี ตัวจัดการจะแสดงรายการน้อยลงและปฏิเสธมากขึ้น และทั้งสองส่วนจะบอกไว้ที่ด้านบนแทนที่จะแสร้งว่ารายชื่อคือทั้งเครื่อง หน้าต่างมี Restart as admin ให้ มันไม่ยกระดับสิทธิ์ตัวเองเลย

จะทำเซิร์ฟเวอร์พังไหม

ไม่ได้ทำเอง ไม่มีอะไรถูกเปลี่ยนหากไม่มีแผนที่คุณได้เห็น ไดรเวอร์ถูกปฏิเสธ และแผนที่จะทำให้สิ่งที่เครื่องต้องใช้ล้มลงจะบอกไว้ สิ่งที่มันป้องกันคุณไม่ได้คือการทำตามแผนที่คุณไม่ได้อ่าน รายชื่อบริการที่เครื่องต้องใช้เป็นรายชื่อตั้งต้น 7 ตัว ได้แก่ RPC สองส่วนและตัวเปิด DCOM ตัวจัดการบัญชี การแยกคีย์ ตัวจัดการเซสชัน และ plug and play และ รีโมตเดสก์ท็อปไม่อยู่ในนั้น ดังนั้นเมื่อทำผ่านเซสชันระยะไกล ให้อ่านแผน

นี่เป็นผลิตภัณฑ์ของ Microsoft ไหม

ไม่ใช่ {{product}} เป็นโครงการโอเพนซอร์สอิสระ และไม่มีส่วนเกี่ยวข้อง ไม่ได้รับการรับรองหรือสนับสนุนโดย Microsoft Windows เป็นเครื่องหมายการค้าของกลุ่มบริษัท Microsoft

โปรแกรมมีภาษาของฉันไหม

ไม่มี โปรแกรมใช้ภาษาอังกฤษ ซึ่งเป็นเหตุผลที่เว็บไซต์นี้ถูกแปล หน้าต่างอ่านไฟล์ภาษา languages\gui.<code>.json ที่วางไว้ข้างไฟล์ปฏิบัติการและเลือกตามภาษาของ Windows โดยไม่มีสวิตช์ การแปลจึงเป็นการมีส่วนร่วมที่เพิ่มได้โดยไม่ต้องสร้างโปรแกรมใหม่ ชื่อบริการในรายชื่อเป็นอย่างที่ Windows ของคุณบอก คือในภาษาที่ Windows ของคุณตั้งไว้

ทำไมหน้าต่างเป็นสีเข้มเมื่อ Windows ของฉันเป็นสีอ่อน

มันเป็นสีเข้มและคงเป็นสีเข้มไม่ว่า Windows จะตั้งอะไรไว้ รวมถึงธีมคอนทราสต์สูง นี่ตรวจสอบแล้วไม่ใช่สมมติ มันใช้สีของตัวเองและอ่านได้ และไม่ทำตามการตั้งค่านั้น

โดยการออกแบบ

  • เฉพาะเครื่องนี้เท่านั้น การจัดการระยะไกลไม่อยู่ในเวอร์ชันนี้ ถ้าจะเปรียบเทียบสองเครื่อง ให้สร้างสแนปช็อตบนแต่ละเครื่องแล้ว diff ไฟล์ทั้งสอง
  • Windows เท่านั้น 64 บิตเท่านั้น Windows 10 1809 หรือ Windows Server 2019 ขึ้นไป
  • การดำเนินการกับไดรเวอร์ถูกปฏิเสธแทนที่จะลอง เพราะการหยุดไดรเวอร์เคอร์เนลมักย้อนกลับไม่ได้ถ้าไม่รีสตาร์ต
  • เครื่องมือไม่ยกระดับสิทธิ์ของตัวเอง เมื่อตัวจัดการปฏิเสธ มันจะบอกและจบด้วยรหัสออก 3 หน้าต่างเสนอให้รีสตาร์ตตัวเองเป็นผู้ดูแลระบบ และไม่ทำอะไรอย่างอื่นเกี่ยวกับเรื่องนี้
  • ไม่ตรวจการเพิกถอนใบรับรอง มันต้องเข้าถึงเครือข่าย และเครื่องมือนี้ไม่ทำเช่นนั้น ดังนั้น Trusted หมายถึงสายใบรับรองถูกต้องบนเครื่องนี้ ไม่ใช่ว่าไม่มีใครเพิกถอนใบรับรองตั้งแต่นั้น
  • หน้าต่างแตกไฟล์บางส่วนของเฟรมเวิร์กส่วนติดต่อผู้ใช้ของ Windows ก่อนเริ่ม เมื่อเป็นไฟล์เดียว มันพกไลบรารีเนทีฟไม่กี่ตัวที่ Windows โหลดได้จากดิสก์เท่านั้น เมื่อไม่มีสิทธิ์ผู้ดูแลระบบ มันเขียนไลบรารีเหล่านั้นตอนเริ่มครั้งแรกของแต่ละเวอร์ชันลงโฟลเดอร์ .net ใต้โฟลเดอร์ชั่วคราวของบัญชี และโหลดจากที่นั่น เมื่อมีสิทธิ์ผู้ดูแลระบบ มันใช้ ProgramData\BetterWindowsServices บนไดรฟ์ Windows แทน เป็นโฟลเดอร์ที่มันสร้างเพื่อให้เฉพาะผู้ดูแลระบบเปลี่ยนได้ และตรวจทุกครั้งที่เริ่ม ถ้าสร้างโฟลเดอร์นั้นไม่ได้ หรือมีคนอื่นเปลี่ยนมันได้ หน้าต่างจะไม่เริ่มและบอกว่าโฟลเดอร์ไหนและต้องทำอย่างไร การย้ายไปที่นั่นหมายความว่าหน้าต่างที่ยกระดับสิทธิ์เริ่มตัวเองเป็นครั้งที่สอง ซึ่งใช้เวลาเสี้ยววินาที และแต่ละเวอร์ชันทิ้งไลบรารีของตัวเองไว้ที่นั่น (ประมาณ 8 MB) จนกว่าจะมีคนลบโฟลเดอร์ บรรทัดคำสั่งไม่มีไลบรารีแบบนั้นและไม่แตกไฟล์อะไร
  • เซสชันที่ยกระดับสิทธิ์จะระบุการตั้งค่า .NET ที่สืบทอดมาแทนที่จะปฏิเสธ โปรไฟเลอร์ สวิตช์การติดตามหรือดัมป์ หรือพอร์ตวินิจฉัยที่ตั้งไว้ในสภาพแวดล้อม ปิดจากภายในโปรแกรม .NET ไม่ได้ ดังนั้นเมื่อมีสิทธิ์ผู้ดูแลระบบ ทั้งสองส่วนจะแสดงรายการที่พบ ส่วน startup hook จะถูกปิดทั้งหมด

สิ่งที่ Windows ทำซึ่งเครื่องมือนี้รายงานตามที่เป็น

  • บริการที่โฮสต์อยู่ใน svchost มีพาธการเปิดใช้งานที่ระบุโฮสต์ ดังนั้น ไฟล์อยู่ตรงนั้น และ ใครลงลายเซ็น จึงบอกได้น้อยกว่าบริการที่มีกระบวนการของตัวเอง
  • ไฟล์ที่มีทั้งลายเซ็นของตัวเองและรายการแค็ตตาล็อกของ Windows อาจระบุผู้ลงลายเซ็นสองคนที่ต่างกัน ผู้เผยแพร่ที่แสดงคือคนที่อยู่ภายในไฟล์ คือคนที่ยังเหมือนเดิมเมื่อดูไฟล์บนเครื่องอื่น และอาจต่างจากที่ PowerShell รายงาน
  • เมื่อไม่มีสิทธิ์ผู้ดูแลระบบ ตัวจัดการแสดงรายการน้อยลงและปฏิเสธรายการที่แสดงมากขึ้น ทั้งสองส่วนบอกไว้ที่ด้านบน และสแนปช็อตบันทึกเรื่องนี้ เพราะการเปรียบเทียบสแนปช็อตที่ยกระดับสิทธิ์กับอันที่สร้างโดยไม่มีสิทธิ์ จะรายงานรายการว่าถูกลบทั้งที่ไม่มีใครลบ

พบปัญหา หรือบริการที่เครื่องมือนี้รายงานต่างจาก sc.exe ใช่ไหม ตัวติดตามปัญหา เปิดอยู่ และ diff ระหว่างสองอย่างนั้นคือสิ่งที่มีประโยชน์ที่สุดที่คุณวางลงไปได้

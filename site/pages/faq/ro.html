Întrebări și limite

Un instrument care nu acoperă ceva în tăcere este mai rău decât unul care spune ce nu poate face. Limitele sunt și ele pe această pagină, în două grupuri: ce refuză prin construcție și ce face Windows și acest instrument raportează așa cum este.

Cu ce se deosebește de sc.exe, Get-Service sau services.msc?

sc query și Get-Service vă spun ce rulează. services.msc vă lasă să schimbați, un rând pe rând, fără o cale de a pune o întrebare și fără nicio evidență după aceea. Acest instrument pune întrebarea (start:auto !status:running), vă arată planul înainte să acționeze și păstrează un instantaneu pe care îl puteți compara peste o săptămână. Acolo unde nu este de acord cu sc.exe despre un serviciu, este o eroare - o parte din suita de teste le rulează pe amândouă și le compară intrare cu intrare. Comparația mai lungă este aici.

Are nevoie de internet?

Niciodată. Fără telemetrie, fără verificare de actualizări, fără raportare de erori, fără cont, fără client de orice fel. Singura dată când poate atinge o rețea este când dați --follow-network: atunci poate privi o cale de lansare pe un share al altei mașini și poate lăsa Windows să preia un certificat pe care această mașină nu îl are deja - dezactivat implicit, iar ajutorul spune de ce. Butoanele GitHub și Donate din fereastră și pagina din meniul Help predau fiecare browserului dumneavoastră o singură adresă fixă când le apăsați, iar browserul este cel care se conectează.

Are nevoie de drepturi de administrator?

Pentru a privi, nu. Pentru a schimba, da. Fără ele managerul arată mai puține intrări și refuză mai multe, iar ambele jumătăți spun asta sus, în loc să se prefacă că lista este toată mașina. Fereastra oferă Restart as admin. Nu își ridică niciodată singură drepturile.

Este gratuit? Îl pot folosi la serviciu?

Da la amândouă. GPL-3.0, fără condiții ascunse. Un instantaneu pe care îl faceți este fișierul dumneavoastră.

Îmi va strica serverul?

Nu de la sine. Nimic nu se schimbă fără un plan pe care l-ați văzut, driverele sunt refuzate, iar un plan care ar doborî ceva de care mașina are nevoie spune asta. Ceea ce nu vă poate proteja este executarea unui plan pe care nu l-ați citit. Lista serviciilor de care mașina are nevoie este o listă de pornire de șapte - cele două jumătăți ale RPC și lansatorul DCOM, managerul de conturi, izolarea cheilor, managerul de sesiuni și plug and play - iar Remote Desktop nu este pe ea, deci într-o sesiune la distanță citiți planul.

Este un produs Microsoft?

Nu. {{product}} este un proiect open source independent și nu este afiliat cu Microsoft, nici aprobat sau sponsorizat de Microsoft. Windows este o marcă comercială a grupului de companii Microsoft.

Este programul în limba mea?

Nu - programul vorbește engleza, motiv pentru care acest site este tradus. Fereastra citește un fișier de limbă, languages\gui.<cod>.json, așezat lângă executabil și îl alege după limba Windows, fără comutator, deci o traducere este o contribuție care se poate adăuga fără recompilarea programului. Numele serviciilor din listă sunt ceea ce spune Windows-ul dumneavoastră că sunt - în limba în care este configurat Windows-ul dumneavoastră.

De ce este fereastra întunecată când Windows-ul meu este luminos?

Este întunecată și rămâne întunecată indiferent cum este setat Windows, inclusiv o temă cu contrast ridicat. Asta este verificat, nu presupus - își păstrează culorile proprii și rămâne lizibilă și nu urmează acea setare.

Prin construcție

  • Doar mașina locală. Administrarea la distanță nu este în această versiune. Pentru a compara două mașini, faceți un instantaneu pe fiecare și comparați cele două fișiere.
  • Doar Windows, doar pe 64 de biți, Windows 10 1809 sau Windows Server 2019 și mai noi.
  • Operațiile asupra driverelor sunt refuzate, nu încercate, pentru că oprirea unui driver de nucleu adesea nu se poate anula fără repornire.
  • Instrumentul nu își ridică singur drepturile. Când managerul refuză, spune asta și se încheie cu codul de ieșire 3. Fereastra se oferă să repornească singură ca administrator și nu face nimic altceva în privința asta.
  • Revocarea certificatelor nu este verificată. Ar necesita accesul la rețea, iar acest instrument nu face niciodată asta. Deci Trusted înseamnă că lanțul era valid pe această mașină, nu că nimeni n-a revocat certificatul de atunci.
  • Fereastra despachetează o parte din cadrul de interfață al Windows înainte să pornească. Ca un singur fișier, poartă câteva biblioteci native pe care Windows le poate încărca doar de pe disc. Fără drepturi de administrator le scrie, la prima pornire a fiecărei versiuni, într-un folder .net sub folderul temporar al contului și le încarcă de acolo. Cu drepturi de administrator folosește în schimb ProgramData\BetterWindowsServices de pe unitatea Windows - un folder pe care îl creează astfel încât doar administratorii să îl poată modifica și pe care îl verifică la fiecare pornire. Dacă folderul nu poate fi creat sau alții îl pot modifica, fereastra nu pornește și spune ce folder și ce trebuie făcut. Mutarea acolo înseamnă că o fereastră cu drepturi ridicate se pornește singură a doua oară, ceea ce durează o fracțiune de secundă, iar fiecare versiune își lasă acolo bibliotecile (cam 8 MB) până când cineva șterge folderul. Linia de comandă nu poartă astfel de biblioteci și nu despachetează nimic.
  • O sesiune cu drepturi ridicate numește setările .NET pe care le moștenește, în loc să le refuze. Un profiler, o opțiune de urmărire sau de dump ori un port de diagnostic setat în mediu nu pot fi dezactivate din interiorul unui program .NET, așa că, cu drepturi de administrator, ambele jumătăți le listează pe cele pe care le găsesc. Cârligele de pornire sunt dezactivate complet.

Lucruri pe care le face Windows și acest instrument le raportează așa cum sunt

  • Un serviciu găzduit în svchost are o cale de lansare care numește gazda, deci fișierul este acolo și cine l-a semnat spun amândouă mai puțin decât pentru un serviciu cu propriul proces.
  • Un fișier cu semnătură proprie și cu intrare într-un catalog Windows poate numi doi semnatari diferiți. Editorul afișat este cel din interiorul fișierului - cel care rămâne același când fișierul este privit pe altă mașină - și poate diferi de ce raportează PowerShell.
  • Fără drepturi de administrator, managerul listează mai puține intrări și refuză mai multe din ce listează. Ambele jumătăți spun asta sus, iar un instantaneu o consemnează, pentru că altfel compararea unui instantaneu cu drepturi ridicate cu unul fără ele ar raporta ca eliminate intrări pe care nimeni nu le-a eliminat.

Ați găsit o problemă sau un serviciu pe care acest instrument îl raportează altfel decât sc.exe? Urmăritorul de probleme este deschis, iar o comparație între cele două este cel mai util lucru pe care îl puteți lipi acolo.
